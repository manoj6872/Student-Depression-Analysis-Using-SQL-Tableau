# Student Depression Analysis Using SQL & Tableau

## Project Overview
This project focuses on analyzing student depression patterns using SQL Server and Tableau. The objective is to explore how academic pressure, study satisfaction, sleep duration, financial stress, and other lifestyle factors relate to student depression.

## Tools & Technologies
- SQL Server
- Tableau
- Microsoft Excel / CSV
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset
The dataset contains 502 student records and 11 columns, including:
- Gender and Age
- Academic Pressure
- Study Satisfaction
- Sleep Duration
- Dietary Habits
- Study Hours
- Financial Stress
- Family History of Mental Illness
- Depression

## Project Workflow

1. Imported the student dataset into SQL Server.
2. Performed data cleaning and standardized gender values.
3. Created age groups using SQL CASE statements.
4. Analyzed academic pressure and study satisfaction.
5. Examined sleep duration, dietary habits, and financial stress.
6. Analyzed depression distribution.
7. Created interactive visualizations and a Tableau dashboard.

## SQL Concepts Used
- SELECT and WHERE
- GROUP BY and ORDER BY
- UPDATE statements
- ALTER TABLE
- CASE statements
- COUNT and aggregate functions
- Data type conversion
- Data cleaning

## Tableau Dashboard
Created a dashboard named **Student Count Analysis**, with visualizations covering:
- Age and Study Satisfaction
- Academic Pressure and Study Satisfaction
- Financial Stress and Study Satisfaction
- Gender Analysis
- Sleep Duration
- Study Hours
- Study Satisfaction

## Key Learning Outcomes
- Practical experience in SQL data cleaning and analysis.
- Understanding relationships between academic and lifestyle factors.
- Developing Tableau dashboards.
- Converting raw datasets into meaningful visual insights.

## Disclaimer
This project is for educational and exploratory data analysis purposes only. It does not provide medical diagnoses or establish causal relationships.
